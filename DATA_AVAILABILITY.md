# Data and code availability

The source code and author-generated simulation summaries in this directory are released under LICENSE and LICENSE-OUTPUTS.md. The full finite-element campaign inputs, trained estimator weights, and raw run tree are not included because they are large local artifacts and contain environment-specific paths.

The façade and DEN experimental observations were digitized from published figures. Their local derivatives are withheld from this repository because the source-specific redistribution terms were not verified. The cited sources and local hashes are listed in DATASETS_AND_LINKS.csv; users must obtain authorized copies from the authoritative sources.

The public code repository is https://github.com/Johnsonlijian/cracktocause-sbi. No archive DOI is claimed. The manuscript is local and has not been uploaded to a journal or repository.
