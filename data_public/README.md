# External digitized inputs

The local project contains four digitized files used by the manuscript:

- `giardina2013_fig5_exp_crackmaps.npz`
- `giardina2013_fig7_crack_widths.csv`
- `giardina2013_fig8_applied_profiles.csv`
- `nooru1992_fig428_crackmaps.npz`

They were transcribed from published figures. Their redistribution terms were not
verified in this local audit, so the files are intentionally **not included** in the
release candidate. Obtain them from the cited source only after confirming the
publisher/repository terms, then place them in this directory with the exact names
above. The local hashes are recorded in `DATASETS_AND_LINKS.csv`.
